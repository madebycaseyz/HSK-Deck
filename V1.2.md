## Summary

## Decisions locked

| Topic | Decision |
|-------|----------|
| Baskets | Unrated → **Main** only. **Know it well** / **Review again** remove the word from Main. Re-rating moves between Know and Review. |
| Swipe left | Current card flies left; next card stays put underneath (unchanged). |
| Swipe right | Previous card slides in from the left (undo of left swipe). Current card does **not** fly right. |
| Copy | Rename “I know it well” → **“Know it well”** everywhere. |
| Word list | Browse-only. Link `All words (N)`. Badges **M** / **K** / **R** (K green, R red). |
| Deck complete | Swipe left from last card to open; swipe right to return. Full-screen. Keep **Start from beginning** + ← Decks. Remove **Back to decks**. |
| Amplitude | Browser SDK. API key via `VITE_AMPLITUDE_API_KEY` in `.env.local` (not committed). |

## Implementation notes

### 1. Mutually exclusive decks

- [`src/domain/decks.ts`](src/domain/decks.ts) `getDeckWords`: `main` → words with no rating; `know` / `review` unchanged
- [`src/App.tsx`](src/App.tsx) `handleRate`: after rating, word leaves main; clamp/advance indexes
- [`src/components/DeckSelect.tsx`](src/components/DeckSelect.tsx): **Know it well**; main resume based on filtered main length
- Tests: `decks.test.ts` for exclusivity and re-rate moves

### 2. Swipe-right = take card back

- [`src/components/StudySession.tsx`](src/components/StudySession.tsx)
- Left: keep exit-overlay fly-left + pinned under
- Right: keep current fixed; animate previous in from left; then `onFlipNavigate(-1)`
- Last-card left → complete screen

### 3. Full word list

- Screen: `{ name: 'wordList', level }` in App
- Link on DeckSelect: `All words (N)` (`N` = full level size)
- New `WordList.tsx`: scrollable rows; badges M / K / R; K = `--know`, R = `--review`

### 4. Deck complete UX

- Swipe left on last card → complete; swipe right on complete → last card
- Use `.page.study` full viewport; remove **Back to decks**

### 5. Amplitude

- Package: `@amplitude/analytics-browser`
- Wrapper: `src/analytics/amplitude.ts` — `initAnalytics()`, `track()`
- Key: `VITE_AMPLITUDE_API_KEY` in `.env.local` (gitignored; see `.env.example`)
- Must set the key **before** `npm run build` / `cap:sync` so Amplitude is included in the iOS bundle
- Privacy: update App Store privacy answers when shipping (analytics = data collected)

### 6. Version

- Bump `APP_VERSION` / iOS `MARKETING_VERSION` to **1.2** when archiving

```
unrated → Main
Main --rate Know--> Know it well
Main --rate Review--> Review again
Know ↔ Review (re-rate)
```
