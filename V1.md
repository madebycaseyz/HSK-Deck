## Review reminder plan (shipped)

### Approach
1. **Pre-prompt:** “Enjoying HSK Deck?” → **Yes** / **Not really** / **Not now**
2. **Yes** → native StoreKit review (plugin); don’t ask again
3. **Not really** → support email **madebycaseyz@gmail.com**; don’t ask to rate again
4. **Not now** → ask again after **10 more** unique known words

### When
| Rule | Decision |
|------|----------|
| “Learnt” | Unique words marked **I know it well** across all levels |
| First ask | Know-count reaches **10** |
| After Not now | Know-count +**10** since last prompt |
| After Yes / Not really | Stop prompts for this install |
| Conflict | Hidden while in-app update prompt is visible |
